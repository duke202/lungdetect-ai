# LungDetect AI

An educational machine-learning project that detects pneumonia from chest X-ray images using transfer learning. Built for our school's *Tech for Change* program.

## Goal
Explore how AI can assist medical triage in resource-limited settings by flagging signs of pneumonia in chest X-rays — reducing diagnostic delays where radiologists are scarce.

## Approach
- Train a convolutional neural network (transfer learning on a pre-trained model)
- Evaluate with accuracy, precision, recall, and a confusion matrix
- Visualize model attention with Grad-CAM heatmaps
- Deploy a simple web app for testing

## Dataset
Public, anonymized "Chest X-Ray Images (Pneumonia)" dataset (~5,800 labeled images).

## Tech Stack
Python · TensorFlow/Keras · Google Colab · Gradio

## Status
🚧 In development

## Disclaimer
This is an educational prototype, **not** a diagnostic tool. It is not validated for clinical use and is designed to assist — not replace — medical professionals.
